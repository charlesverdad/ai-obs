ai-obs · data dictionary

What ai-obs Collects

Every field the daemon persists, where it comes from, and what a real row looks like. One SQLite file, all local: ~/.local/share/ai-obs/ai-obs.db. Nothing leaves the machine.

hook pushed by Claude Code hooks (HTTP, live) sampler measured from the kernel (proc_pid_rusage) transcript tailed from ~/.claude/projects/*.jsonl computed derived by the daemon

Privacy defaults. Commands are stored as a two-word digest (just test, cargo build) — never the full command line with flags and paths. Environment variables are never read (the kernel forbids it unprivileged — verified, not just promised). Sample rows below are illustrative, with values taken from real measurement runs.

agent_span — fact, one row per subagent lifetime

The subagent's own timeline, distinct from the tool_span rows it spawns inside it. Opened by SubagentStart, closed by SubagentStop — or swept closed at SessionEnd (abnormal termination), or by a periodic staleness sweep (daemon crashed and the session was never resumed) if neither ever arrived. Never closed on daemon startup: sessions survive restarts and a subagent may legitimately still be running. Draws the agent lane in the replay gantt and the TIME column in top's agent rows.

fieldtypesourcemeaning
idINTEGER PKcomputed
session_idTEXT FKhook→ session
agent_idTEXThookSame id PreToolUse/PostToolUse carry for calls made inside this agent — the join key to tool_span
agent_typeTEXThookThe agent's frontmatter name, e.g. Explore, general-purpose
started_atINTEGER mshookSubagentStart. A redelivered Start for the same agent_id is ignored — first write wins (UNIQUE(session_id, agent_id))
ended_atINTEGER mshookSubagentStop, the SessionEnd sweep, or the stale sweep. Only ever set once — a later close never overwrites an earlier one
end_reasonTEXTcomputedstop = normal SubagentStop · session_end = closed by the SessionEnd sweep · stale = still open 24h after started_at, closed by the detector loop's periodic sweep
-- sample agent_id a1e2c9f0-… agent_type Explore started_at …19:56:40.112 ended_at …19:57:12.884 end_reason stop

tailer_checkpoint — bookkeeping

Byte offset per transcript file, so a daemon restart resumes instead of re-reading 495 project directories. Offsets only advance past complete lines; a partially-written line is retried next poll.
